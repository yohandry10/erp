Fecha de actualizacion: 2026-07-24

Este archivo registra decisiones que ya fueron tomadas y no deben redescubrirse, reabrirse o revertirse sin evidencia nueva. Sirve para que Codex, Opus o cualquier agente no duplique analisis ni implemente una segunda arquitectura.

## Reglas de uso

- Si una decision afecta arquitectura, seguridad, offline, CPE/fiscal, BD, migraciones, release o coordinacion de agentes, debe quedar aqui.
- Si una decision cambia, actualizar esta entrada con fecha, motivo, evidencia y documentos relacionados.
- Si el codigo actual contradice una decision, verificar primero si el codigo es mas reciente; luego actualizar `CURRENT_STATE.md`, `FLOW_STATUS.md` y este archivo.
- No usar auditorias historicas para revertir una decision vigente sin contrastar codigo actual.

## Como agregar una decision

Usar una fila nueva con ID estable por dominio:

- `DOC-*` para reglas documentales.
- `AUTH-*` para autenticacion/sesiones/permisos.
- `OFF-*` para desktop/offline.
- `CPE-*` para fiscal/CPE/GRE/SUNAT/OSE.
- `DB-*` para base de datos/migraciones.
- `STOCK-*` para inventario/kardex.
- `REL-*` para release/go-live.

Formato minimo:

```md
| ID | Decision | Estado | Razon | Fuente relacionada |
```

Si una decision queda obsoleta, no borrarla de inmediato. Cambiar `Estado` a `Reemplazada` y agregar la decision nueva que la reemplaza.
