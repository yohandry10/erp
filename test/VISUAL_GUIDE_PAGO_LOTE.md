## 📱 Responsive Design

El wizard se adapta a diferentes tamaños de pantalla:

- **Desktop**: Grid de 2-4 columnas para información
- **Tablet**: Grid de 2 columnas
- **Mobile**: Columna única, información apilada

## 🔄 Flujo de Datos

```
Usuario → Página → Wizard → API → Backend
                     ↓
                  Validaciones
                     ↓
              Procesamiento
                     ↓
              Resultado ← API
                     ↓
              Pantalla de Éxito
```
